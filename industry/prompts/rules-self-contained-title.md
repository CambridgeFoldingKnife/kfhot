
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：指南名 / 器械名 / 机构名 / 研究主题 / 量表名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 没信息量的 teaser（如 "Update"、"New"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "Guideline update" + 来源 "某学会官网" → "某学会更新脑卒中康复指南"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体名称时，用上位词（如"某康复指南"）兜底，绝不凭"行业常识"编一个具体名称 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、教程或综述标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的指南、器械或新数据，就改写成“发布 / 推出 / 上线 / 获批”。只有原标题明确宣布了发布、推出或获批，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、器械、主题名。
   例：原标题 "How to dose early mobilization after stroke" → "脑卒中后早期活动如何确定剂量"，不能写成 "某团队发布早期活动方案"。
   例：原标题 "A review of telerehabilitation in knee OA" + 来源和正文明确是某康复中心 → "某康复中心的膝骨关节炎远程康复综述"，不能只写成缺主体的 "远程康复综述"。
